CSCI-2479 Advanced Web Programming

Project: CRUD Application using MVC Pattern with Agile Practices
Purpose: This project aims to provide learners with hands-on experience of building a CRUD
(Create, Read, Update, Delete) application using the PHP Laravel framework, following the
MVC (Model-View-Controller) design pattern. Additionally, learners will practice Agile
methodologies, including creating requirements as issues in GitHub and using a Scrum/Kanban
board to manage and track progress.
Objectives: Learners will be able to:
• Develop a functional CRUD application using PHP and Laravel.
• Implement the MVC design pattern in a web application.
• Utilize GitHub for version control and issue tracking.
• Apply Agile practices to manage project development.
• Deliver a complete project with documented code and a video walkthrough.
Technology Requirements:
•  PHP 7.4 or higher
• Laravel 8.x
• Composer
• Git and GitHub account
• Docker (optional for advanced deployment)
• An IDE or code editor (such as Visual Studio Code, PHPStorm)
Project Scope: Students can choose to build one of the following applications:
• Library Management System
• E-commerce Application
• Custom application of similar complexity (must be approved by the instructor)
High-Level Features: Each application should include the following:
• User authentication and authorization.
• CRUD operations for primary entities (e.g., books, products).
• Search functionality.
• Responsive design with basic UI.
• RESTful API endpoints for CRUD operations.
Milestones and Deliverables:
Milestone 1: Project Initialization and Requirement Gathering
▪ Tasks:
  ▪ Create a GitHub repository for the project.
  ▪ Add all project requirements as issues in GitHub.
  ▪ Include a high-level description of the application features in the README
file.
 Deliverables:
  ▪ GitHub repository URL.
  ▪ README file with high-level features description.
  ▪ Issues listed in GitHub.
  ▪ Video Walkthrough: Demonstrating the GitHub repository setup and issue
creation.
Milestone 2: Scrum Board Setup and Initial Planning
o Tasks:
  ▪ Create a Scrum/Kanban board in GitHub Projects.
  ▪ Plan and organize issues into the board, categorizing them as To Do, In
Progress, and Done.
  ▪ Demonstrate progress by moving issues across the board.
o Deliverables:
  ▪ Scrum/Kanban board link.
  ▪ Video Walkthrough: Demonstrating the board setup and issue
categorization.
Milestone 3: Basic Application Setup
o Tasks:
  ▪ Set up a new Laravel project.
  ▪ Implement basic user authentication (registration, login, logout).
  ▪ Create initial migrations and models for the primary entities.
o Deliverables:
  ▪ URL to the GitHub repository with the updated code.
  ▪ Video Walkthrough: Demonstrating the Laravel setup, user authentication,
and initial migrations/models.
Milestone 4: Implement CRUD Operations
o Tasks:
  ▪ Develop CRUD functionality for the primary entities.
  ▪ Ensure proper validation and error handling.
  ▪ Create views and controllers to manage the CRUD operations.
o Deliverables:
  ▪ URL to the GitHub repository with the updated code.
  ▪ Video Walkthrough: Demonstrating the CRUD operations and related
features.
Milestone 5: Advanced Features and Testing
o Tasks:
  ▪ Implement search functionality.
  ▪ Set up unit tests for the application services.
  ▪ Use mocks/stubs for testing dependencies.
o Deliverables:
▪ URL to the GitHub repository with the updated code.
▪ Video Walkthrough: Demonstrating the search functionality and testing
setup.
Milestone 6: Deployment and Final Documentation
o Tasks:
  ▪ Prepare the application for deployment (optional: use Docker for
containerization).
  ▪ Deploy the application to a cloud service (e.g., AWS, Heroku).
  ▪ Update the README file with deployment instructions and project
documentation.
  ▪ Record a final video walkthrough demonstrating the application features.
o Deliverables:
  ▪ URL to the live deployed application.
  ▪ URL to the GitHub repository with the final code and updated README.
  ▪ Video Walkthrough: Demonstrating the deployment process and final
application features.
